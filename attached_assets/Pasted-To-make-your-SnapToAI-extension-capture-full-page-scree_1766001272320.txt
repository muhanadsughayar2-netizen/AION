To make your SnapToAI extension capture full-page screenshots in Google Docs reliably (without blanks or missing content), we'll force the page to render the full canvas by injecting aggressive style modifications—similar to what GoFullPage does (based on common extension techniques like expanding containers, setting overflows to visible, and removing sticky/position limits). This expands the virtual canvas without needing scrolling for short Docs or combines with your existing scroll for long ones.
Your code already has expandForFullPage(), but it skips for custom containers like Docs' .kix-appview-editor. We'll fix that by always applying expansions for Docs, targeting Doc-specific classes to force full height/render.
Step 1: Update content.js
Add a new function forceGoogleDocsFullRender() before capturing, and call it in safeFullPageCapture(). Replace the full safeFullPageCapture() and add the new function:
JavaScript// New function: Force full render for Google Docs by injecting styles
function forceGoogleDocsFullRender() {
  if (!location.hostname.includes('docs.google.com')) return;

  // Remove any existing style to avoid duplicates
  const existing = document.getElementById('snaptoai-docs-styles');
  if (existing) existing.remove();

  const style = document.createElement('style');
  style.id = 'snaptoai-docs-styles';
  style.textContent = `
    /* Force full expansion - like GoFullPage */
    body, html {
      height: auto !important;
      min-height: auto !important;
      max-height: none !important;
      overflow: visible !important;
      position: static !important;
      background-color: #fff !important;
    }
    .kix-appview-editor, .docs-editor, .kix-page-canvas, .kix-canvas-tile-content, canvas {
      height: auto !important;
      min-height: auto !important;
      max-height: none !important;
      overflow: visible !important;
      position: static !important;
      display: block !important;
      visibility: visible !important;
    }
    /* Hide sticky/ fixed elements to avoid duplication */
    [style*="position: sticky"], [style*="position: fixed"], header, nav, .fixed {
      display: none !important;
      visibility: hidden !important;
    }
    /* Expand all containers */
    div, section, main {
      height: auto !important;
      overflow: visible !important;
      position: relative !important;
    }
  `;
  document.head.appendChild(style);

  // Force layout recalculation
  document.body.offsetHeight; // Trigger reflow
}

// In safeFullPageCapture() - call the new function before capture
async function safeFullPageCapture(tabId) {
  try {
    // NEW: Force Docs render before anything
    forceGoogleDocsFullRender();

    // Small delay for styles to apply
    await new Promise(r => setTimeout(r, 200));

    return await performFullPageCapture(tabId);
  } catch (error) {
    // ... (existing error handling)
  }
}

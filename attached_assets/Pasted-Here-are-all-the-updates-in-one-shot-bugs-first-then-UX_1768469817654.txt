Concurrent Capture Race (Makes snaps always work one after the other, no mix-ups)
File: background.js
Where: At the top of the file, before any capture code.
Exact code:textlet captureQueue = [];
let isProcessing = false;

async function processQueue() {
  if (isProcessing || captureQueue.length === 0) return;
  isProcessing = true;
  const nextCapture = captureQueue.shift();
  try {
    await nextCapture();  // Run the capture function
  } catch (e) {
    console.error('[SnapToAI Capture Error]', e);
  }
  isProcessing = false;
  processQueue();  // Next
}

JPEG Quality Validation (Fixes bad numbers in settings for perfect pictures)
File: popup.js (the options one)
Where: Replace the jpegQuality input listener.
Exact code:textdocument.getElementById('jpegQuality').addEventListener('input', (e) => {
  let val = parseInt(e.target.value);
  val = Math.max(1, Math.min(100, val || 90));  // Clamp 1-100, default 90
  e.target.value = val;
  document.getElementById('jpegQualityValue').textContent = val + '%';
});

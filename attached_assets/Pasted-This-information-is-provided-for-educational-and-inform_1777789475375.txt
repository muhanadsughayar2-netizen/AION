### 1. The Fix for buildClipScenes (Line 2706)
The Problem: Currently, this function sends your entire trailer script to every single 8-second clip. Veo gets overwhelmed trying to fit a 30-second script into 8 seconds, and since every clip gets the same script, you just get the same scene repeated three times.

The Solution: Use Gemini to "Storyboard" the script into 3 distinct visual scenes.

Replace your current buildClipScenes with this:

async function buildClipScenes(prompt, clipCount, apiKey, clipDur) {
  if (clipCount < 2) return [prompt];
  
  // 1. Call Gemini to act as the "Director" and break the prompt into parts
  const directorUrl = `https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-pro:generateContent?key=${apiKey}`;
  const directorPrompt = `You are a Cinematographer. Take this video request: "${prompt}". 
    Break it into ${clipCount} distinct visual scenes for an 8-second clip each. 
    Scene 1: The Hook. Scene 2: The Action. Scene 3: The Result.
    Return ONLY a JSON array of strings. No extra text.`;

  try {
    const response = await fetch(directorUrl, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ contents: [{ parts: [{ text: directorPrompt }] }] })
    });
    const data = await response.json();
    const storyboard = JSON.parse(data.candidates[0].content.parts[0].text.match(/\[[\s\S]*\]/)[0]);
    
    // 2. Map these unique scenes to your compiler
    return storyboard.map((scene, i) => compileScenePrompt({
      userPrompt: scene, // Each clip now gets a UNIQUE visual instruction
      styleBible: "Cinematic, 4k, professional lighting",
      vibe: "Tech Trailer",
      shot: scene,
      index: i,
      total: clipCount,
      clipDur
    }));
  } catch (e) {
    console.error("Director failed, falling back to literal prompts", e);
    return Array(clipCount).fill(prompt); // Fallback if API fails
  }
}
### 2. The Fix for compileScenePrompt (Line 2744)
The Problem: Your current code wraps prompts in brackets like [USER REQUEST]. This is "token noise." AI models like Veo treat brackets as literal characters or confusing metadata, which degrades the visual quality.

The Solution: Use clean, natural language bridges.

Replace your compileScenePrompt with this:

function compileScenePrompt({ userPrompt, styleBible, vibe, index, total }) {
  const style = styleBible ? ` Style: ${styleBible}.` : '';
  const energy = vibe ? ` Mood: ${vibe}.` : '';
  
  if (index === 0) {
    return `Scene Start: ${userPrompt}.${style}${energy} Establish the cinematic look.`;
  } else {
    return `Continuing the scene: ${userPrompt}.${style}${energy} Maintain the same characters and lighting from the previous shot. No hard cuts.`;
  }
}

✅ Why You See This Error

The error message:

Uncaught IndexSizeError: Failed to execute 'getImageData' on 'CanvasRenderingContext2D': The source width is 0.

This means:

Your extension was trying to run:

ctx.getImageData(x, y, w, h)


…but w or h = 0
So the screenshot canvas was empty or 0×0 pixels.

This happens when:

The tab is not fully loaded

The screenshot returned from chrome.tabs.captureVisibleTab has 0 dimensions

The code tries to “pixelate” or process a screenshot that is not ready

The popup opens before the screenshot image finishes loading

Or the Replit-generated code created a broken placeholder image

This is not your fault — Replit’s automatic code generation added an unnecessary pixelation effect function that breaks when the image is small or missing.

And that giant block of repeating gibberish text in your console is the Base64 screenshot trying to print — that’s normal, just noisy.

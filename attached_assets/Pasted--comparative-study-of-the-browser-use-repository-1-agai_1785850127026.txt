 comparative study of the browser-use repository[1] against your MV3 Chrome Extension agent reveals key architectural patterns that can help resolve the "80% success rate" ceiling and improve self-healing.
Conventional web agents often struggle with selector fragility (brittle XPaths breaking when layouts change)[2] and visual drift (mismatch between where the model thinks an element is and its actual physical position). browser-use tackles these issues through three core design choices[3][4][5]:
Interactive Element Indexing: The agent does not read raw HTML or generic page text. It downsamples the DOM into a structured tree of only interactive elements, assigning each a temporary numeric ID[6]. The LLM performs actions directly on these indices (e.g., click(index: 12))[7], removing selector guessing entirely.
Multi-Strategy Selector Cascading: If an action fails, the engine uses a priority-ranked list of fallback selectors (IDs, data-attributes, relative text, structural XPaths) recorded at execution time to recover the element[8][9].
Proactive Watchdogs: Watching for popups, JavaScript alerts, and loading spinners in the background so they are dismissed before they block focus or intercept actions[10][11].
The following sections explain how to adapt these three production-grade patterns directly into your MV3 Chrome Extension.
Pattern 1: Interactive Element Indexing (The DOM State Map)
Instead of sending the LLM raw page text or full DOM trees (which clutter context and confuse vision models), we can inject a script on the page to build a Structured Interactive Map. This script identifies visible, actionable elements, tags them with a temporary attribute (data-aion-idx), and outputs a compact list to the LLM.
This approach minimizes token overhead[6], improves coordinate accuracy, and allows the LLM to specify actions using a simple index number rather than complex selectors.
Add this indexing helper to your content.js file:
code
JavaScript
// content.js

/**
 * Traverses the visible DOM and builds a structured map of interactive elements,
 * tagging them with a temporary index for the LLM.
 */
function buildInteractiveDomMap() {
  const interactiveSelectors = [
    'button', 'a', 'input', 'textarea', 'select', 
    '[role="button"]', '[role="link"]', '[role="tab"]',
    '[contenteditable="true"]', '[tabindex]:not([tabindex="-1"])'
  ].join(',');

  const elements = document.querySelectorAll(interactiveSelectors);
  const domMap = [];
  let index = 0;

  // Clear any existing index attributes from prior steps
  document.querySelectorAll('[data-aion-idx]').forEach(el => {
    el.removeAttribute('data-aion-idx');
  });

  elements.forEach(el => {
    const rect = el.getBoundingClientRect();
    const style = window.getComputedStyle(el);
    
    // Check if the element is actually rendered and visible
    const isVisible = rect.width > 2 && 
                      rect.height > 2 && 
                      style.display !== 'none' && 
                      style.visibility !== 'hidden' &&
                      style.opacity !== '0';
                      
    if (!isVisible) return;

    // Tag the physical element with our index
    el.setAttribute('data-aion-idx', index);

    const tag = el.tagName.toLowerCase();
    const text = (el.innerText || el.value || el.placeholder || el.getAttribute('aria-label') || el.title || '').trim().replace(/\s+/g, ' ').slice(0, 60);
    const type = el.getAttribute('type') || '';
    const role = el.getAttribute('role') || '';

    // Build a compact, token-efficient representation for the prompt
    domMap.push(`[Index ${index}] <${tag}${type ? `:${type}` : ''}${role ? ` role="${role}"` : ''}> "${text}"`);
    index++;
  });

  return domMap.join('\n');
}

// Expose the map generator to your message listener
window.buildInteractiveDomMap = buildInteractiveDomMap;
How to integrate this in ai-chat.js:
In your getActiveTabPageText or snapshot call inside ai-chat.js, retrieve this interactive map and prepend it to the user's prompt during agent runs. Update your model's tools to accept an index parameter (e.g. click(index: 12)) alongside text or selector.
Pattern 2: Multi-Strategy Selector Cascading (Self-Healing)
browser-use records a Selector Map at the moment an element is first discovered[8]. If the page structure changes or the primary selector fails on a subsequent step, it attempts a ranked cascade of alternative strategies[9][12].
We can implement this cascade directly inside background.js under the click or type action handlers. If the primarily requested locator fails, the script will automatically fallback to testing other identifying attributes:
code
JavaScript
// background.js (inside handleAgentAction or click block)

/**
 * Attempts to resolve and click an element using a prioritized cascade of locators,
 * providing autonomous self-healing before reporting a failure.
 */
async function selfHealingClick(tabId, params, cdpCmd) {
  const { index, text, selector, description } = params;

  // S1: Try the direct interactive index first (Pattern 1)
  if (index !== undefined) {
    try {
      const idxResult = await cdpCmd('Runtime.evaluate', {
        expression: `(() => {
          const el = document.querySelector('[data-aion-idx="${index}"]');
          if (el) {
            el.scrollIntoView({ behavior: 'auto', block: 'center' });
            const r = el.getBoundingClientRect();
            return { x: r.left + r.width/2, y: r.top + r.height/2, found: true };
          }
          return { found: false };
        })()`,
        returnByValue: true
      });
      if (idxResult?.result?.value?.found) {
        const { x, y } = idxResult.result.value;
        await dispatchCdpClick(cdpCmd, x, y);
        return { success: true, method: 'index_match' };
      }
    } catch (_) {}
  }

  // S2: Try stable data attributes (data-testid, data-id)
  if (selector) {
    try {
      const selectorsToTry = [
        selector,
        `[data-testid="${selector}"]`,
        `[data-id="${selector}"]`,
        `#${selector}`
      ];
      for (const sel of selectorsToTry) {
        const box = await getBoxModelBySelector(sel, cdpCmd);
        if (box) {
          await dispatchCdpClick(cdpCmd, box.x, box.y);
          return { success: true, method: 'data_attribute_match' };
        }
      }
    } catch (_) {}
  }

  // S3: Try exact and partial accessible names (ARIA / Label / Text)
  const labelText = text || description;
  if (labelText) {
    try {
      const cleanLabel = labelText.toLowerCase().trim();
      const textMatchResult = await cdpCmd('Runtime.evaluate', {
        expression: `(() => {
          const needle = ${JSON.stringify(cleanLabel)};
          const candidates = document.querySelectorAll('button, a, [role="button"], input[type="submit"]');
          for (const el of candidates) {
            const label = (el.innerText || el.getAttribute('aria-label') || el.placeholder || el.value || '').toLowerCase().trim();
            if (label === needle || label.includes(needle)) {
              el.scrollIntoView({ behavior: 'auto', block: 'center' });
              const r = el.getBoundingClientRect();
              return { x: r.left + r.width/2, y: r.top + r.height/2, found: true };
            }
          }
          return { found: false };
        })()`,
        returnByValue: true
      });
      if (textMatchResult?.result?.value?.found) {
        const { x, y } = textMatchResult.result.value;
        await dispatchCdpClick(cdpCmd, x, y);
        return { success: true, method: 'semantic_text_match' };
      }
    } catch (_) {}
  }

  // S4: Relative / Positional XPath search
  if (labelText) {
    try {
      const xpathResult = await cdpCmd('Runtime.evaluate', {
        expression: `(() => {
          const txt = ${JSON.stringify(labelText)};
          const xpath = "//*[self::button or self::a or @role='button'][contains(translate(text(), 'ABCDEFGHIJKLMNOPQRSTUVWXYZ', 'abcdefghijklmnopqrstuvwxyz'), '" + txt.toLowerCase() + "')]";
          const result = document.evaluate(xpath, document, null, XPathResult.FIRST_ORDERED_NODE_TYPE, null);
          const el = result.singleNodeValue;
          if (el) {
            el.scrollIntoView({ behavior: 'auto', block: 'center' });
            const r = el.getBoundingClientRect();
            return { x: r.left + r.width/2, y: r.top + r.height/2, found: true };
          }
          return { found: false };
        })()`,
        returnByValue: true
      });
      if (xpathResult?.result?.value?.found) {
        const { x, y } = xpathResult.result.value;
        await dispatchCdpClick(cdpCmd, x, y);
        return { success: true, method: 'xpath_fallback' };
      }
    } catch (_) {}
  }

  return { success: false, error: 'Element unresolved after all cascading strategies.' };
}

async function dispatchCdpClick(cdpCmd, x, y) {
  const base = { x, y, button: 'left', buttons: 1, clickCount: 1 };
  await cdpCmd('Input.dispatchMouseEvent', { ...base, type: 'mousePressed' });
  await new Promise(r => setTimeout(r, 50));
  await cdpCmd('Input.dispatchMouseEvent', { ...base, type: 'mouseReleased' });
}

async function getBoxModelBySelector(selector, cdpCmd) {
  try {
    const { root } = await cdpCmd('DOM.getDocument', { depth: 0 });
    const { nodeId } = await cdpCmd('DOM.querySelector', { nodeId: root.nodeId, selector });
    if (!nodeId) return null;
    await cdpCmd('DOM.scrollIntoViewIfNeeded', { nodeId });
    const box = await cdpCmd('DOM.getBoxModel', { nodeId });
    if (!box?.model?.content) return null;
    const [x1, y1, x2, , , y3] = box.model.content;
    return { x: (x1 + x2) / 2, y: (y1 + y3) / 2 };
  } catch (_) {
    return null;
  }
}
Pattern 3: Proactive Modal and Interruption Dismissal (Watchdog)
Dynamic overlays (cookie notices, registration gates, newsletter popups) often block clicks or hijack tab focus mid-run, causing the agent to hang[11]. We can build a lightweight interruption check directly into the click flow.
Before dispatching any click or typing action, execute this evaluation script to check if the target coordinates are obscured by a full-screen or high-z-index overlay, and attempt to auto-dismiss it if found:
code
JavaScript
// content.js or as a Runtime.evaluate string in background.js

/**
 * Checks if the target point (x, y) is obscured by an overlay/popup
 * and attempts to find and click a close button on that overlay.
 */
function dismissBlockingOverlays(targetX, targetY) {
  const topElement = document.elementFromPoint(targetX, targetY);
  if (!topElement) return false;

  // Find the parent container of the blocking element
  let current = topElement;
  let isOverlay = false;
  
  while (current && current !== document.body) {
    const style = window.getComputedStyle(current);
    const zIndex = parseInt(style.zIndex, 10);
    const isFixedOrAbsolute = style.position === 'fixed' || style.position === 'absolute';
    
    // Heuristic: high z-index fixed containers covering large areas are usually modals
    if (isFixedOrAbsolute && zIndex > 100 && current.offsetHeight > window.innerHeight * 0.3) {
      isOverlay = true;
      break;
    }
    current = current.parentElement;
  }

  if (isOverlay && current) {
    console.log('[Aion Watchdog] Blocking overlay detected:', current);
    
    // Find close buttons inside the overlay
    const closeSelectors = [
      'button[aria-label*="close" i]',
      'button[class*="close" i]',
      '[id*="close" i]',
      '.close-btn',
      '.modal-close'
    ].join(',');
    
    const closeBtn = current.querySelector(closeSelectors) || 
                     Array.from(current.querySelectorAll('button, span, a')).find(el => 
                       /^(close|dismiss|✕|×|hide|cancel)$/i.test((el.innerText || '').trim())
                     );
                     
    if (closeBtn) {
      console.log('[Aion Watchdog] Dismissing overlay using:', closeBtn);
      closeBtn.click();
      return true; // Successfully intercepted and dismissed
    }
  }
  return false;
}
By integrating this dismissBlockingOverlays check into your background.js click routing block before running cdpMouseClick(), the agent can dynamically recover when websites trigger unprompted popups[11].

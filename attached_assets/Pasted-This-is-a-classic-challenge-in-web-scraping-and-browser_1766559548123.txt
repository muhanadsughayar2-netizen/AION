This is a classic challenge in web scraping and browser automation. Google Docs and Gmail are not "normal" webpages; they use Virtual Rendering.

In a normal page, everything exists in the HTML. In Google Docs/Gmail, the system only "paints" the text you can see on the screen. When you scroll, it deletes the old text and paints the new text. Your current code is trying to force the height to auto, which causes Google Docs to "break" and render blank pages because its internal engine (called Kix) gets confused when the container size changes.

Here is the exhaustive solution to fix the Google Docs and Email capture.

The Problem: Why it's failing
Google Docs: When you set height: auto, the Google Docs canvas engine stops rendering because it thinks the "viewport" is infinite. It loses its place and shows white space.
Gmail: The scroll container isn't the "body"; it’s a deeply nested div that changes its ID frequently.

To keep your "Snap To AI" extension functional on the Free Tier, you must strategically manage the 5 Requests Per Minute (RPM) and Tokens Per Minute (TPM) limits. Since image analysis is "token-heavy," the Free Tier's 1,000,000 TPM limit for Gemini 2.0 Flash can be exhausted quickly by large screenshots.Here are the most effective ways to make it work for free:1. Drastic Image Compression (The Biggest "Quick Win")The primary reason you hit limits is the image resolution. Gemini calculates tokens based on the pixels processed.Downscale in Browser: Use a hidden <canvas> to resize the snip before sending it. For a "simple analysis," you don't need a high-resolution image.Optimal Settings: Set your target width/height to 768px or 1024px max.Target Low Resolution: Explicitly set media_resolution: "LOW" in your API request to drop the token cost per image from ~560 tokens (Medium) down to 280 tokens.2. Implement Client-Side ThrottlingThe "5 RPM" limit means you can only send one request every 12 seconds.Visual Feedback: When a user clicks the star, show a "Preparing AI analysis..." spinner. If they click too quickly, queue the next request and show a countdown timer (e.g., "AI is thinking, next snip ready in 8s").Automatic Delay: Use a global variable to track the last request time and block new ones until 12 seconds have passed.3. Use the Files API for "Magical" ChatsCurrently, your code likely re-sends the base64 image with every follow-up question in the chat portal. This hits the TPM limit immediately.Upload Once: Use the Gemini Files API to upload the snip once. It’s free and stores files for 48 hours.Reference the URI: Instead of sending the base64 data again, use the file_uri in your subsequent chat turns. This reduces follow-up requests to almost zero image tokens.4. Smart Prompting & System InstructionsShorten Default Prompt: Instead of "Give a simple analysis of this image: summary, key points, and suggestions for what to ask next," use a System Instruction to define the model's behavior once.System Instruction: "You are a concise visual analyst. For every image, provide a 2-sentence summary and 3 bullet points."User Prompt: Just send "Analyze" to trigger it. This saves text tokens on every call.5. Multi-Key Rotation (The "Advanced" Free Method)If you want to offer more capacity to your users for free, you can allow them to input multiple API keys from different projects.Key Pool: Store an array of keys and rotate to the next one whenever you receive a 429 error.Disclaimer: Each key must belong to a separate Google Cloud project to have its own independent quota.Summary Checklist for "Free Forever"FeatureOptimizationImpactResolutionResize to 768px + set media_resolution: LOW-50% Token usageFiles APIUpload snip once; use file_uri for chat-90% Token usage in chatThrottlingForce 12-second delay between requestsPrevents 429 ErrorsSystem PromptsDefine persona once in system instructionsSaves text tokensWould you like me to provide a code snippet for the canvas-based image resizing to help reduce your token usage immediately?

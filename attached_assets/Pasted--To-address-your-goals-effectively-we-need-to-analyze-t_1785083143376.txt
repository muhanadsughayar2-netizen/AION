2. Traverse the Accessibility Tree (AXTree) via CDP
For Google Docs and Sheets, traditional DOM querying is often ineffective because text is rendered dynamically on a canvas or within nested structures.
Instead of searching for standard selectors, use Chrome DevTools Protocol (CDP) to interact with the Accessibility Tree. This allows the agent to find elements by their semantic roles and labels (e.g., finding a button labeled "Extensions" or "Insert").
If your background script utilizes chrome.debugger, you can query the accessibility tree like this:
code
JavaScript
async function getAccessibilityTree(tabId) {
  return new Promise((resolve, reject) => {
    const target = { tabId };
    chrome.debugger.attach(target, "1.3", () => {
      if (chrome.runtime.lastError) return reject(chrome.runtime.lastError);
      
      chrome.debugger.sendCommand(target, "Accessibility.getFullAXTree", {}, (result) => {
        chrome.debugger.detach(target);
        if (chrome.runtime.lastError) return reject(chrome.runtime.lastError);
        resolve(result.nodes);
      });
    });
  });
}
This tree returns a standardized structure that your agent can read to find button coordinates or input fields, regardless of how complex the dynamic HTML obfuscation is.
3. Handle Shadow DOM Piercing
Many parts of Google AI Studio and NotebookLM use Web Components with closed or open Shadow Roots. Your standard click and type tools should automatically attempt to pierce shadow roots when searching for elements.
Ensure the DOM utility function running inside your target tab uses a shadow-piercing query selector:
code
JavaScript
// Helper to pierce Shadow DOMs recursively
function querySelectorAllShadow(selector, el = document) {
  const arr = [];
  const walk = (node) => {
    if (!node) return;
    if (node.nodeType === Node.ELEMENT_NODE) {
      if (node.matches(selector)) arr.push(node);
      if (node.shadowRoot) walk(node.shadowRoot);
    }
    let child = node.firstChild;
    while (child) {
      walk(child);
      child = child.nextSibling;
    }
  };
  walk(el);
  return arr;
}

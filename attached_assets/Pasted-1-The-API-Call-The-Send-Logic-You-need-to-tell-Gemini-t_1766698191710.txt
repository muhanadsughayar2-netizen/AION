1. The API Call (The "Send" Logic)
You need to tell Gemini to return AUDIO instead of just text. Use the Kore voice for a professional, expensive feel.

JavaScript

const response = await model.generateContent({
  contents: [{ 
    role: 'user', 
    parts: [{ text: "Give me a pro-level analysis of this market data." }] 
  }],
  generationConfig: {
    // This tells Gemini to speak natively
    responseModalities: ["AUDIO"], 
    speechConfig: {
      voiceConfig: {
        prebuiltVoiceConfig: {
          voiceName: "Kore" // Options: Kore, Puck, Charon, Fenrir
        }
      }
    }
  }
});
2. The Audio Player (The "Play" Logic)
Gemini sends back a string of data. You need this helper function in your JavaScript to turn that data into actual sound.

JavaScript

function playAIVoice(base64Data) {
  // 1. Convert the base64 string from Gemini into a playable format
  const audioBlob = `data:audio/wav;base64,${base64Data}`;
  const audio = new Audio(audioBlob);
  
  // 2. Play the professional voice
  audio.play().catch(error => {
    console.error("Audio playback failed. Make sure you interacted with the page first!", error);
  });
}

// HOW TO USE IT:
// Extract the audio from the Gemini response
const audioContent = response.candidates[0].content.parts[0].inlineData.data;
playAIVoice(audioContent);
3. Why this makes it "WOW" for your users
No Latency: Unlike old systems that wait for text and then convert it, Gemini 3.0 Flash creates the voice at the same time as the text. It's almost instant.

Premium Quality: Kore is a high-fidelity voice. It sounds like a human financial analyst from a high-end news station, not a computer.

Emotive: If you tell Gemini in the prompt to "be excited" or "be cautious," the voice will actually change its tone to match!

1. The Root Cause: Why Extension Builds Break
In Chrome Extensions (Manifest V3), popups run under an origin of chrome-extension://<EXTENSION_ID> which enforces a strict Content Security Policy (typically script-src 'self').
The Block: When you render generated code inside an <iframe> via a srcdoc or Blob URL inside the popup, Chrome treats the frame with the same strict extensions origin.
The Crash: Any remote Javascript script (such as <script src="https://cdn.tailwindcss.com"> or <script src="https://unpkg.com/lucide">) is flagged as dynamic code execution and blocked.
The Result: The page falls of its design system and renders as unstyled, plain, unpainted HTML with non-functional scripts.

📂 File 1: Create sandbox.html (Put this in your Extension folder)
Create a new file named sandbox.html in your extension's root directory. It runs under a relaxed sandbox context, enabling the Tailwind compiler and Lucide icons to boot up cleanly:
code
Html
<!-- sandbox.html -->
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Nexus Extension Sandbox Frame</title>
  <!-- Remote CDNs are allowed inside sandbox.html because it is sandboxed! -->
  <script src="https://cdn.tailwindcss.com"></script>
  <script src="https://unpkg.com/lucide@latest"></script>
</head>
<body class="bg-black text-[#f8fafc] font-sans antialiased min-h-screen">
  <div id="sandbox-app"></div>
  <script>
    // Listen for incoming code chunks injected from the extension popup
    window.addEventListener('message', (event) => {
      const { htmlCode } = event.data;
      if (htmlCode) {
        document.getElementById('sandbox-app').innerHTML = htmlCode;
        try {
          lucide.createIcons();
        } catch (e) {
          console.error("Lucide setup failed inside sandbox:", e);
        }
      }
    });

    // Notify popup that the sandbox window has completed booting
    window.parent.postMessage({ sandboxReady: true }, '*');
  </script>
</body>
</html>

function _showLivePreview(code) {
  const iframe = document.getElementById('livePreview');
  const w = document.getElementById('previewWrapper');
  const building = document.getElementById('previewBuilding');
  const lbl = document.getElementById('previewLabel');

  if (w) w.style.display = 'block';
  if (building) building.style.display = 'none';
  if (lbl) lbl.textContent = '🏗️ LIVE PREVIEW';

  if (iframe) {
    iframe.style.display = 'block';
    iframe.style.height = _previewExpanded ? '420px' : '200px';
    
    // Post the compiled markup straight to our sandboxed document view
    if (iframe.contentWindow) {
      iframe.contentWindow.postMessage({ htmlCode: code }, '*');
    }
  }
}

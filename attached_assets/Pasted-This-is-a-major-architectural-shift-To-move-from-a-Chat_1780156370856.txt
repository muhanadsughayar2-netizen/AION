1. Tab Switching Logic
// Handle Workspace Tab Switching
document.querySelectorAll('.ws-tab').forEach(tab => {
  tab.addEventListener('click', () => {
    const target = tab.dataset.tab;
    
    // Update active tab button
    document.querySelectorAll('.ws-tab').forEach(t => t.classList.remove('active'));
    tab.classList.add('active');
    
    // Update active pane
    document.querySelectorAll('.ws-pane').forEach(p => p.classList.remove('active'));
    document.getElementById(`ws-${target}`).classList.add('active');
  });
});

  e.currentTarget.classList.toggle('tool-btn-active', buildModeEnabled);
  
  if (buildModeEnabled) {
    workspace.classList.remove('hidden');
    // Switch to Preview tab by default when starting

});

Summary of Changes
Layout: You now have a 3-pane setup. Screenshots on the left, Code/Preview in the middle, and Chat on the right.
Code View: Instead of code just being a bubble in the chat, it now lives in a dedicated "Code" tab with a file list on the side, exactly like Google AI Studio.
Real-time sync: When you type a prompt like "Change the background to blue," the Preview tab will update the site, and you can click the Code tab to see the updated HTML instantly.
Pro-Tip: If you want the code to look even better (with colors), you can replace the #codeDisplay element with a library like Prism.js or Monaco Editor, but the code above will get you the professional layout immediately! [1], [2]

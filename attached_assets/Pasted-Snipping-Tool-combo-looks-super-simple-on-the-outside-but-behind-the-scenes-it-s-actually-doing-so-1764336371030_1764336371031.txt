What the Snipping Tool actually does (step by step):

Puts a dark/transparent overlay over your entire screen
So you feel like you’re “drawing on top” of everything.
Lets you drag a rectangle (or freeform, window, full-screen)
It’s just listening to your mouse: on Mouse Down → record start position, on Mouse Move → draw rectangle in real-time, on Mouse Up → finish.
Takes a perfect screenshot of ONLY the area you selected
This is the key part everyone thinks is magic.
Opens the image in its own little editor
Where you can draw arrows, highlight, etc.

The “magic” part: How does it capture exactly your rectangle so perfectly?
It uses a Windows’ built-in function called BitBlt (Bit Block Transfer) or the newer Desktop Duplication API. Here’s super simplified pseudo-code of how almost the entire snipping tool could be written in C# (the language Microsoft uses):
C#// 1. Press Win + Shift + S → darken screen and start capture mode
OverlayWindow.ShowFullScreenDarkOverlay();

// 2. User drags mouse to select area
Rectangle selectedArea = WaitForUserToDragRectangle();

// 3. THE IMPORTANT PART: Capture exactly that rectangle from screen
Bitmap screenshot = new Bitmap(selectedArea.Width, selectedArea.Height);

using (Graphics g = Graphics.FromImage(screenshot))
{
    g.CopyFromScreen(
        selectedArea.X,              // source X
        selectedArea.Y,              // source Y
        0, 0,                        // destination X,Y in bitmap
        selectedArea.Size,           // size to copy
        CopyPixelOperation.SourceCopy);
}

// 4. Show the captured image in editor
EditorWindow.Show(screenshot);
That CopyFromScreen line? That’s literally 90% of the entire Snipping Tool.
Microsoft has had this function since Windows XP. It’s crazy fast and perfect.
Even simpler in Python with pywin32:
Pythonimport win32gui
import win32ui
import win32con
from PIL import Image

def snip():
    # Get full screen dimensions
    hwnd = win32gui.GetDesktopWindow()
    w = win32gui.GetWindowRect(hwnd)[2)[2]
    h = win32gui.GetWindowRect(hwnd)[3]

    # ... wait for user to select rectangle (x1,y1,x2,y2) ...

    wDC = win32gui.GetWindowDC(hwnd)
    dcObj = win32ui.CreateDCFromHandle(wDC)
    cDC = dcObj.CreateCompatibleDC()
    bitmap = win32ui.CreateBitmap()
    bitmap.CreateCompatibleBitmap(dcObj, width, height)
    cDC.SelectObject(bitmap)
    
    cDC.BitBlt((0,0), (width, height), dcObj, (left, top), win32con.SRCCOPY)

    bmpinfo = bitmap.GetInfo()
    bmpstr = bitmap.GetBitmapBits(True)
    img = Image.frombuffer('RGB', (bmpinfo['bmWidth'], bmpinfo['bmHeight']), bmpstr, 'raw', 'BGRX', 0, 1)

    dcObj.DeleteDC()
    cDC.DeleteDC()
    win32gui.ReleaseDC(hwnd, wDC)
    win32gui.DeleteObject(bitmap.GetHandle())

    img.save("snip.png")
So yes – the entire “amazing” Snipping Tool is basically:

Draw overlay
Let user drag rectangle
Call Windows’ built-in CopyFromScreen / BitBlt
Show image

That’s it. The rest is just pretty UI, saving to clipboard, OCR (in newer versions), recording for video snip, etc.

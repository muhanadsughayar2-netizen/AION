In annotate.js, the lazy loader uses the following logic to cache pages:

The Root Cause: getImageData extracts uncompressed raw pixel data (RGBA arrays) from the canvas. On modern screens (with a high Device Pixel Ratio/Retina displays), a single captured window can easily be 
 of raw RAM.
When executing a full-page capture with 30–50 steps, loading all elements into pageOriginalImages at once attempts to allocate 
 of continuous heap memory inside the V8 engine. This triggers an immediate garbage-collector bottleneck, causing extreme lag and the "Aw, Snap!" browser tab crash.
2. The Chunking Side-Effect ("Saved Parts")
To combat the crashing, the safe-stitching logic was capped:
code

Instead of stitching a beautiful, unified page, the script forces pagination into discrete batches (e.g., Part 1/3, Part 2/3). While this keeps the extension from crashing, it fragments the single full-page capture into "parts."
3. Storage Serialization Bottleneck
The extension relies heavily on exchanging base64 data URLs:
code
JavaScript

The Root Cause: chrome.storage.local serializes data into JSON strings on the main thread. Serializing/deserializing multi-megabyte arrays of screenshots causes the extension's background process to lock up completely, creating "heavy lagging" during saves.

// Replace this function in your annotate.js
async function loadPageImage(index) {
  if (index < 0 || index >= pages.length) return;
  if (pageImages[index]) return; // Already exists

  return new Promise((resolve) => {
    const img = new Image();
    img.onload = () => {
      pageImages[index] = img;
      
      // FIX: Never use tempCtx.getImageData() globally for all pages.
      // Instead, keep the compressed Image object in memory.
      // We will only perform pixel analysis or stitching on-the-fly sequentially, 
      // preventing massive RAM allocation.
      pageOriginalImages[index] = null; // Kill the heavy arrays!
      resolve();
    };
    img.onerror = () => {
      resolve();
    };
    img.src = pages[index];
  });
}

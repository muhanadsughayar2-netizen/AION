Technical Refactor: "Workspace Mode" & IDE Layout
I want to completely transform the "Build Mode" experience. Currently, it is a messy chat flow with long code blocks. I want it to look and behave like a professional IDE (e.g., Google AI Studio).

1. The Layout Refactor (ai-chat.html)
Refactor the .main-content into a Three-Pane Workspace:

Left Sidebar (Sidebar-A): Create a toggle between "Screenshots" and "File Explorer." When buildModeEnabled is true, default to the File Explorer.
Show 3 files: 📄 index.html, 🎨 styles.css, and ⚡ main.js.
Clicking a file must update the "Code" tab in the Center HUD.
Center Workspace (The HUD): Upgrade the #previewWrapper into a persistent tabbed window.
Tab 1: Preview (The iframe showing the app).
Tab 2: Code (A scrollable, dark-themed <pre> block).
Right Sidebar (Sidebar-B): This is the Gemini Chat. Keep it narrow (max 350px) so the user can prompt while looking at the code/preview.
2. The "Blueprint Card" Logic (ai-chat.js)
Stop the AI from outputting raw code into chat bubbles. It makes the chat too long.

Silent Streaming: When the AI generates code, pipe it directly into the variables _buildBodyHtml, _buildStyleCss, and _buildScriptJs.
Status Card: Instead of code, the AI should drop a single "Blueprint Card" using the magic-card CSS.
The card must show a progress list: "Structure," "Design," and "Logic."
Flip Animation: Add a CSS 3D-flip effect to the card. When the AI finishes one stage (e.g., L1 HTML) and moves to the next (e.g., L2 CSS), trigger the flip animation to show the project is "evolving."
3. File & HUD Synchronization
The Code Tab in the HUD must be "File Aware." If I click styles.css in the Left Sidebar, the HUD must instantly show the content of _buildStyleCss.
While the AI is streaming, add a small "pulsing" green dot next to the filename in the sidebar that is currently being updated.
Ensure renderLivePreview updates the Preview Tab and the Code Tab simultaneously.
4. The "Chat-to-Fix" Workflow
The chat input at the bottom must remain fixed and accessible at all times.
The user should be able to say "Change the background to red" and see the Blueprint Card flip, the Sidebar pulse, and the Preview HUD update without any new code blocks cluttering the chat history.
5. Constraints & UX
Popup Width: Since this is a Chrome Extension, ensure the layout uses flex: 1 for the Center Workspace so it takes the most space.
Visual Style: Use a high-end "Dark Studio" aesthetic. Borders should be rgba(255, 255, 255, 0.05). Tab active states should use the --st-accent color.
Please implement these changes across ai-chat.html and ai-chat.js now. Use the existing staged build logic (L1, L2, L3) but route all output to this new IDE UI.

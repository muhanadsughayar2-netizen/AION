The "Talk Show" Orchestration Code
To turn your Aion AI Studio into a multi-voice talk show, you need a backend function that acts as a "Director." It must split your script by character and assign a unique voice to each.

1. The Multi-Voice Backend (Python)
This function uses a "Voice Map" to ensure Zephyr, Kore, and Puck always sound different.

import os
from openai import OpenAI # Replit managed OpenAI
from google import genai # Replit managed Google (Lyria)

client_ai = OpenAI()
client_google = genai.Client()

def generate_talk_show_assets(source_material):
    # STEP 1: Summarize into a 3-person script
    script_prompt = f"Summarize this into a talk show script. Characters: Zephyr (Host), Kore (Expert), Puck (Creative). Format: SPEAKER: TEXT. Source: {source_material}"
    
    # Use Gemini to write the script
    script_response = client_google.models.generate_content(model="gemini-2.5-flash", contents=script_prompt)
    script_lines = script_response.text.split('\n')

    # STEP 2: Voice Mapping (The Secret to Multi-Voice)
    voice_map = {
        "Zephyr": "onyx",   # Deep, authoritative host
        "Kore": "shimmer",  # Professional, clear expert
        "Puck": "alloy"     # Neutral, energetic creative
    }

    # STEP 3: Generate Background Music (Lyria)
    music = client_google.models.generate_content(
        model="lyria-3-clip-preview",
        contents="Soft, upbeat lo-fi talk show background music, instrumental only."
    )

    return {
        "script": script_lines,
        "music_url": music.parts[0].file_data.file_uri,
        "voice_map": voice_map
    }

Why Your Extension Builds are Breaking (The Root Cause)
When building Chrome Extensions (Manifest V3), the Content Security Policy (CSP) is strictly enforced at the extension container level. When you embed an iframe inside your extension popup page:
Loading remote scripts via CDNs like <script src="https://cdn.tailwindcss.com"> or <script src="https://unpkg.com/lucide"> is permanently blocked. Standard Manifest V3 prevents the execution of any remote Javascript.
Even inside high-security iFrames, these scripts cannot boot up, resulting in unstyled HTML text and non-functional JS.
The Two Ways to Fix Your Code on Replit/Chrome
You can solve this in your Chrome Extension in two ways:
Option A (Recommended for standard extensions): Download tailwind.min.js and lucide.min.js locally, package them within your extension directory, and update your code to load them as 'self'.
Option B (The Pure Way): Feed Gemini a specialized No-CDN system prompt that instructs the AI to generate modern, beautiful single-file HTML sites using Vanilla CSS templates and Custom Inline SVGs, entirely bypassing CDN scripts.
Below are the direct files and code updates you should make to your Chrome Extension.

let streamThrottleTimer = null;
let pendingStreamHtml = null;
let pageBuildWatchdog = null;

// Call this during your API response streaming loop
function handleHtmlStreamProgress(chunkText) {
  const previewWrapper = document.getElementById('previewWrapper');
  const buildingSpinner = document.getElementById('previewBuilding');
  const iframe = document.getElementById('livePreview');
  const previewLabel = document.getElementById('previewLabel');
  const indicatorText = document.getElementById('previewBuildingTxt');

  // Activate Visual Pipeline
  if (previewWrapper) previewWrapper.style.display = 'block';
  if (buildingSpinner) buildingSpinner.style.display = 'flex';
  if (previewLabel) previewLabel.textContent = '⏳ COMPILING SITE...';
  if (indicatorText) indicatorText.textContent = 'Synthesizing live layout layers...';

  // Extract ongoing HTML
  const { html, truncated } = extractHtmlFromResponse(chunkText, _continuationPending ? _lastBuiltCode : null);
  if (!html) return;

  _lastBuiltCode = html;
  pendingStreamHtml = html;

  // Progressive Rendering Throttle (every 800ms to avoid DOM thrashing)
  if (!streamThrottleTimer) {
    streamThrottleTimer = setTimeout(() => {
      streamThrottleTimer = null;
      if (pendingStreamHtml && iframe) {
        iframe.removeAttribute('src'); // Switch away from blob if active
        iframe.srcdoc = pendingStreamHtml;
        iframe.style.display = 'block';
        iframe.style.height = _previewExpanded ? '420px' : '200px';
        pendingStreamHtml = null;
      }
    }, 800);
  }

  // Safety net: Spinner cannot lock up longer than 45 seconds
  if (!pageBuildWatchdog) {
    pageBuildWatchdog = setTimeout(() => {
      pageBuildWatchdog = null;
      _showLivePreview(_lastBuiltCode);
    }, 45000);
  }
}

// Call this when stream generator resolves complete (done === true)
function handleHtmlStreamComplete(finalText) {
  if (streamThrottleTimer) clearTimeout(streamThrottleTimer);
  if (pageBuildWatchdog) clearTimeout(pageBuildWatchdog);
  
  const { html } = extractHtmlFromResponse(finalText, null);
  if (html) {
    _showLivePreview(html);
  } else {
    const spinner = document.getElementById('previewBuilding');
    if (spinner) spinner.style.display = 'none';
  }
}
Part 2: The Answers to the Specific System Prompt Questions
Here are the concrete solutions you can feed directly to Gemini to generate fully offline, visually astonishing sites that run inside your Chrome extension.
1. Token Strategy (For an 8192 token limit)
When generating highly complex websites, do not attempt a single generation pass. It invites half-finished results, missing closure tags, and broken code.
The Strategy: Use a 3-Level Generation Pass:
L1 (Structure): Solicit only pure HTML tags inside <body> utilising semantic structures and explicit IDs.
L2 (Design): Give Gemini the L1 HTML code and ask for only custom CSS rules within a <style> block.
L3 (Interactivity): Take both outputs and ask Gemini to write modular vanilla Javascript.
Why it works: Keeps the prompt window small (less than 2500 tokens per call), prevents memory overhead, and allows you to catch specific compiler errors before they show up in your preview.
2. CSS Approach
Custom CSS from scratch inside a <style> block beats Tailwind CDN in this specialized scenario.
Why: The Tailwind CDN script runs a heavy runtime engine to find class names and compile styles. This is completely blocked by Manifest V3 because Chrome view filters detect it as dynamically executed evaluation. Custom CSS bypasses this entirely, compiles in milliseconds, and allows the AI to craft bespoke, non-generic glassmorphism layers.

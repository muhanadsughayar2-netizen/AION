How GoFullPage Does It Better
From their FAQ (I verified):

Scrolling & Assembly: Scrolls down/across, assembles into single image — similar to yours.
Dynamic Sites: Waits for load, handles inner scrollables (divs/iframes), prevents fixed elements from repeating.
Complex Pages: Switches techniques for custom JS scrolling — e.g., slower scroll, multiple passes.
Limitations: Even they fail on PDFs, custom JS-managed scrolling (e.g., Adobe Spark), or very large pages (breaks into multiple images).

They succeed more because of 10+ years of tweaks for edge cases — not magic, just more refinements like delays and inner handling.
Exact Fixes for Your Code (Make It Close to GoFullPage)
Add these to your capture script (background/content — the loop that fills fullPageScreenshots).

Add Delay & Smaller Scroll:

JavaScript// In your capture loop
async function captureFullPage() {
  const totalHeight = document.documentElement.scrollHeight;
  let currentScroll = 0;
  const viewportHeight = window.innerHeight;
  const overlap = viewportHeight * 0.2;
  
  while (currentScroll < totalHeight) {
    window.scrollTo(0, currentScroll);
    
    // Delay for lazy load
    await new Promise(resolve => setTimeout(resolve, 500)); // Adjust to 1000 for very dynamic sites
    
    // Capture
    const dataUrl = await chrome.tabs.captureVisibleTab(); // If background, use tabId
    
    pages.push(dataUrl);
    
    // Smaller scroll for better loading
    currentScroll += viewportHeight - overlap;
  }
}

Handle Inner Scrollables (Basic Fix):

JavaScript// Before each capture
function scrollInnerElements() {
  document.querySelectorAll('div[overflow="auto"], div[overflow="scroll"], iframe').forEach(el => {
    el.scrollTop = el.scrollHeight; // Scroll to bottom to load content
    // For iframes, if possible (cross-origin may block)
  });
}

// Call in loop before capture
scrollInnerElements();
await new Promise(r => setTimeout(r, 300));

Check for Blank & Retry:

JavaScript// After capture
if (await isBlank(dataUrl)) {
  await new Promise(r => setTimeout(r, 500)); // Retry delay
  dataUrl = await chrome.tabs.captureVisibleTab();
}

// Helper (add to script)
async function isBlank(dataUrl) {
  const img = new Image();
  img.src = dataUrl;
  await new Promise(r => img.onload = r);
  const canvas = document.createElement('canvas');
  canvas.width = img.width;
  canvas.height = img.height;
  const ctx = canvas.getContext('2d');
  ctx.drawImage(img, 0, 0);
  const data = ctx.getImageData(0, 0, canvas.width, canvas.height).data;
  let nonWhite = 0;
  for (let i = 0; i < data.length; i += 4) {
    if (data[i] < 200 || data[i+1] < 200 || data[i+2] < 200) nonWhite++;
  }
  return nonWhite < (data.length / 4) * 0.2; // <20% non-white = blank
}

How to Fix It
Follow these steps in order. Test your extension after each one.

Clear Session Storage Manually (Quick Fix):
Open your Chrome extension's popup (click the icon).
Right-click inside the popup and select "Inspect" to open DevTools for the popup.
In DevTools, go to the Application tab > Storage > Session Storage (under the origin, e.g., chrome-extension://your-extension-id).
Right-click the items and select "Clear" (or all at once).
If it's localStorage instead (persistent across sessions), clear that too in the same tab.
Close and reopen the popup/extension. This should resolve it temporarily.

Clear via Code (If It Recurs):
Add this to your popup.js (at the top of the script, e.g., before any storage operations):JavaScripttry {
    sessionStorage.clear();  // Or localStorage.clear() if applicable
} catch (e) {
    console.error('Error clearing storage:', e);
}
This auto-clears on load. Reload the extension in chrome://extensions/ after editing.

Optimize Your Code to Avoid the Issue:
Avoid Large Data in SessionStorage: If your extension (or AI feature) is storing uploads/queries/results there, switch to better alternatives:
Use chrome.storage.local (higher quota, up to 5MB default, or unlimited with permissions). Your manifest already has "storage" permission, so in code:JavaScriptchrome.storage.local.set({ key: value }, function() { /* callback */ });
For very large data (e.g., images from Amazon captures), stick to the filesystem API as in the original code (e.g., requestFileSystem), or save directly to downloads via chrome.downloads.download.

Add Unlimited Storage Permission: If you need more space, update manifest.json:JSON"permissions": [ "activeTab", "storage", "unlimitedStorage" ]Reload the extension. This removes quotas for chrome.storage (but not sessionStorage—avoid using it for big stuff).
Handle Uploads/Deletions: In your AI chat or upload logic, add deletion after use. E.g., after processing a upload, call sessionStorage.removeItem('key') or clear old entries.
Chunk Large Data: If storing strings >8KB (per item limit in some storages), split them into smaller pieces.

Browser-Wide Fixes:
Incognito Mode Test: Run in incognito (extensions must be enabled there via chrome://extensions/). Storage is isolated, so it might not be full.
Clear Browser Cache/Storage Globally: Chrome Settings > Privacy and security > Clear browsing data > Advanced > Check "Cookies and other site data" + "Cached images and files." Select time range "All time."
Check for Conflicts: Disable other extensions (especially AI-related ones like "SnapToAI" if that's separate) and test.
Update Chrome: Go to chrome://settings/help and update if available, as older versions have stricter quotas.

The root cause of this "stitching hallucination" is exactly as diagnosed, but the fix needs to be applied directly to how your code constructs the prompt for Veo.

Right now, your compileScenePrompt function takes the entire 24-second master script—including the ending instructions about the metallic SmartConnect logo—and pastes it at the very top of every single 8-second clip. Because Veo pays the most attention to the first few lines of a prompt, it panics and tries to cram the entire 24-second story, including the logo, into Clip 1.

To fix this, we need to remove the master script from the individual clip prompts and let Veo rely entirely on the chunked shot descriptions generated by the AI Director.

Replace these two functions in your ai-chat.js file with the updated code below:

1. Replace compileScenePrompt
This update removes the User brief: block from the top and strictly feeds Veo the specific action for that 8-second window.

JavaScript
function compileScenePrompt({ userPrompt, styleBible, vibe, shot, index, total, clipDur }) {
  const segLen = Number(clipDur) > 0 ? Number(clipDur) : 8;
  const t0 = index * segLen, t1 = (index + 1) * segLen;
  const vibeLine = vibe ? ` Vibe: ${vibe}.` : '';

  // Lead strictly with the AI Director's chunked action for this specific time window.
  // Do NOT include the full userPrompt, or Veo will try to render the ending in Clip 1.
  const shotBlock = `[ACTION FOR THIS SEGMENT — ${t0}s to ${t1}s]\n${shot}\n\n`;

  const styleBlock = styleBible
    ? `[VISUAL STYLE & CONTINUITY]\n${styleBible}${vibeLine}\n\n`
    : (vibeLine ? `[VISUAL STYLE & CONTINUITY]\n${vibeLine.trim()}\n\n` : '');

  const continuity = index === 0
    ? `[DIRECTOR'S NOTE] Establish the scene exactly. Do not rush to the end of the story.`
    : `[DIRECTOR'S NOTE] Same subjects, wardrobe, location, lighting, and palette as the previous segment.`;

  return `${shotBlock}${styleBlock}${continuity}`;
}
2. Replace slimSceneForChainImage
Because we changed the tags in compileScenePrompt, we must also update the slimming function so the visual chaining (passing the last frame to the next clip) continues to work perfectly.

JavaScript
function slimSceneForChainImage(scenePrompt, fallbackBrief) {
  const header = '[CONTINUES FROM ATTACHED FRAME — same look, same subjects, no cut]';
  const text = String(scenePrompt || '');

  // Strip out the style and continuity blocks so Veo just focuses on the action and the chained image
  const trimmed = text
    .replace(/\n*\[VISUAL STYLE[^\]]*\][\s\S]*?(?=\n\[DIRECTOR'S NOTE\]|$)/i, '')
    .replace(/\n*\[DIRECTOR'S NOTE\][^\n]*\n?/i, '')
    .trim();

  // If we successfully trimmed it down to just the action block, use it.
  if (trimmed && trimmed.includes('[ACTION FOR THIS SEGMENT')) {
    return `${header}\n\n${trimmed}`;
  }

  // Legacy fallback if shape isn't recognized
  const brief = String(fallbackBrief || '').trim();
  const tail = trimmed || text.trim();
  const briefBlock = brief ? `[ORIGINAL SCRIPT]:\n${brief}\n\n` : '';
  return `${header}\n\n${briefBlock}${tail}`.trim();
}
